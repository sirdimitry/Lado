# Security and privacy

Lado has no typing history, telemetry or network client. Typed context exists only
in bounded, short-lived RAM. Only explicit settings and exceptions are persisted.

Read [the complete privacy boundaries](docs/PRIVACY.md), including secure-field
detection, permissions, selection handling and the limits of RAM erasure.

Do not include real passwords or private typed text in public reports. Report
security issues to [@sirdimitry](https://x.com/sirdimitry); synthetic reproductions
are preferred.
