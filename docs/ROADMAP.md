# Lado — поэтапный план / phased roadmap

Галочка означает выполненную и проверенную работу, а не обещание.
A checked box means completed work, not a planned capability.

## Этап 0 · Визуальный стиль / identity

- [x] Имя Lado, палитра из трёх плоских цветов.
- [x] Пиксельный логотип с редактируемым SVG и прозрачным PNG.
- [x] Иконка macOS в PNG, SVG и ICNS; монохромный значок меню.
- [x] Широкоформатный баннер GitHub 1280 × 640.
- [x] Правила использования и воспроизводимая генерация графики.

## Этап 1 · Основа и приватность / foundation

- [ ] Общее ядро Python отдельно от системных адаптеров.
- [ ] Кратковременный ограниченный буфер, без истории ввода и сетевого клиента.
- [ ] Явные личные исключения и сохранение только настроек.
- [ ] README на русском и английском, документы приватности и архитектуры.
- [ ] About с гиперссылками X и GitHub автора.

## Этап 2 · macOS и ручной режим / manual conversion

- [ ] Индикатор RU/EN, выбор рабочей пары, пауза на третьем языке.
- [ ] Двойной Shift для последнего слова, включая одну букву.
- [ ] Двойной Shift для выделения и точное обратное преобразование.
- [ ] Защищённые поля: отключение обработки, очистка памяти, значок замка.
- [ ] Настройки, исключения приложений, необязательный автозапуск.
- [ ] Интеграционная проверка в настоящих текстовых и парольных полях macOS.

## Этап 3 · Автоисправление / automatic correction

- [ ] Компактные локальные частотные словари RU/EN с атрибуцией.
- [ ] Защита ЗАГЛАВНЫХ слов, адресов, смешанных токенов и личных исключений.
- [ ] Однобуквенные слова: два согласованных соседа и отложенная проверка.
- [ ] Проверки ложных исправлений и независимые примеры.
- [ ] Проверка реального набора в TextEdit, Safari, Chrome и других редакторах.

## Этап 4 · Предварительная сборка / preview distribution

- [ ] Автоматические проверки ядра, приватности и границ буфера.
- [ ] Сборка самостоятельного Lado.app с иконкой и стабильным bundle ID.
- [ ] DMG с перетаскиванием в Applications, проверка подписи и содержимого.
- [ ] Замер памяти и процессорной нагрузки готового приложения.
- [ ] Коммиты и push исходников в GitHub, предварительный релиз с DMG.
- [ ] Intel-сборка и проверка на Intel Mac.
- [ ] Developer ID и нотариальное заверение Apple, если будет доступен сертификат.

## Этап 5 · Маленькая локальная модель / local model research

- [ ] Отдельный набор неоднозначных и смешанных примеров без личного ввода.
- [ ] Сравнить компактный классификатор со словарным алгоритмом.
- [ ] Измерить качество, задержку и память на реальном Mac.
- [ ] Подключать модель только при измеримом выигрыше; никаких серверных запросов.

## Этап 6 · Windows

- [ ] Адаптер клавиатуры и раскладок Win32 при сохранении общего ядра.
- [ ] Защита парольных полей и взаимодействие с UI Automation.
- [ ] Трей, настройки и About в стиле Windows.
- [ ] Проверки совместимости и установщик.

## Этап 7 · Стабильная версия / stable release

- [ ] Матрица совместимости приложений, смешанные абзацы и форматирование.
- [ ] Длительный тест быстрого набора, сна/пробуждения и смены фокуса.
- [ ] Проверка VoiceOver, светлой/тёмной темы и масштаба интерфейса.
- [ ] Проверка обновления поверх предыдущей версии без потери исключений.
