# Lado — поэтапный план / phased roadmap

Галочка означает выполненную и проверенную работу, а не обещание.
A checked box means completed work, not a planned capability.

## Этап 0 · Визуальный стиль / identity

- [x] Имя Lado, палитра из трёх плоских цветов.
- [x] Пиксельный логотип с редактируемым SVG и прозрачным PNG.
- [x] Иконка macOS в PNG, SVG и ICNS; монохромный значок меню.
- [x] Широкоформатный баннер GitHub 1280 × 640.
- [x] Правила использования и воспроизводимая генерация графики.

## Этап 1 · Основа и приватность / foundation

- [x] Общее ядро Python отдельно от системных адаптеров.
- [x] Кратковременный ограниченный буфер, без истории ввода и передачи текста.
- [x] Явные личные исключения и сохранение только настроек.
- [x] README на русском и английском, документы приватности и архитектуры.
- [x] About с гиперссылками X и GitHub автора.

## Этап 2 · macOS и ручной режим / manual conversion

- [x] Индикатор RU/EN, выбор рабочей пары, пауза на третьем языке — реализация.
- [x] Двойной Shift для последнего слова, включая одну букву — ядро и адаптер.
- [x] Двойной Shift для выделения и точное обратное преобразование — реализация и тесты адаптера.
- [x] Защищённые поля: отключение обработки, очистка памяти, значок замка — реализация и тесты порядка проверок.
- [x] Настройки, выбор исключаемых приложений, необязательный автозапуск.
- [x] Изолированный прогон в настоящих NSTextView и NSSecureTextField: 19 проверок.

## Этап 3 · Автоисправление / automatic correction

- [x] Компактные локальные частотные словари RU/EN с атрибуцией.
- [x] Защита ЗАГЛАВНЫХ слов, адресов, смешанных токенов и личных исключений.
- [x] Однобуквенные слова: два согласованных соседа и отложенная проверка.
- [x] Синтетический набор обычных и ошибочных слов для регрессионных проверок.
- [ ] Проверка реального набора в TextEdit, Safari, Chrome и других редакторах.

## Этап 4 · Предварительная сборка / preview distribution

- [x] Автоматические проверки ядра, приватности и границ буфера.
- [x] Сборка самостоятельного Lado.app с иконкой и стабильным bundle ID.
- [x] DMG с перетаскиванием в Applications, проверка подписи и содержимого.
- [x] Начальный замер памяти и CPU в ожидании разрешений; замер при активном наборе ещё нужен.
- [x] Коммиты и push исходников в GitHub.
- [x] DMG, SHA-256 и архив графики загружены в черновик релиза GitHub.
- [x] Опубликован предварительный релиз [v0.1.0](https://github.com/sirdimitry/Lado/releases/tag/v0.1.0), 2026-10-29.
- [ ] Intel-сборка и проверка на Intel Mac.
- [ ] Developer ID и нотариальное заверение Apple, если будет доступен сертификат.

## Исправление после зависания / input safety revision

- [x] Пассивный listen-only observer; системные нажатия не блокируются.
- [x] AX и редактирование вынесены из callback, очередь ограничена и устаревает.
- [x] Удалена отправка синтетических клавиш, включая fallback выделений.
- [x] Аварийная остановка защёлкивается до перезапуска; автоматического re-arm нет.
- [x] Блокировка одновременного запуска двух копий, очистка источника run loop.
- [x] 82 изолированных теста; macOS добавлена в матрицу CI.
- [ ] Новый живой прогон в отдельной macOS-среде, медленные/зависшие редакторы.
- [ ] Новый проверенный DMG после живого прогона. Старый 0.1.0 не использовать.
