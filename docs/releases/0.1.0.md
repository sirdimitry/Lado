# Lado 0.1.0 — macOS preview

A small RU/EN menu-bar keyboard-layout companion. Text detection and conversion
stay local; there is no typing history, telemetry, account or subscription.

- One **EN / RU** indicator, with an integrated lock badge during protected input.
- Offline correction, ALL-CAPS protection and explicit personal word/app exceptions.
- Double Shift converts the last word (including a single letter) or selected text;
  repeat to reverse the operation.
- A selected RU/EN pair works alongside other installed languages.
- Native settings, pause, optional start at login and About with author links.
- Optional GitHub checks at startup/hourly. A newer matching DMG prompts
  **Update / Later**; Update opens the validated GitHub download in the browser.
  Installation is by dragging the app to Applications, not a silent app replacement.

**Privacy:** update requests contain no typing, personal exceptions or device IDs.
Automatic checks can be disabled. Short-lived bounded RAM context is cleared on
focus changes, pause and idle expiry. Only preferences and explicit exceptions
are intentionally persisted.

**Validation:** 53 automated checks and 19 isolated native live checks passed,
including word/selection reversal and secure-field blocking. The installed app and
test pad were closed after testing. Broader browser/editor compatibility remains
under validation; see docs/VALIDATION.md.

**Apple Silicon only. Ad-hoc signed, not Apple-notarized.** Current idle sample:
77 MB physical footprint. No neural model or Windows adapter in this preview.
DMG integrity and signature checks pass; a SHA-256 file and brand archive are attached.

# Lado 0.1.0 — предварительная версия для macOS

Локальный помощник для раскладок RU/EN: без истории ввода, телеметрии и подписки.

- Один индикатор **EN / RU**, с замком прямо на нём при защищённом вводе.
- Автоисправление, защита ЗАГЛАВНЫХ слов и явные исключения слов/приложений.
- Двойной Shift для последнего слова, одной буквы или выделенного фрагмента;
  повторное нажатие возвращает исходный вариант.
- Выбранная пара RU/EN не требует удалять остальные языки из системы.
- Настройки, пауза, необязательный автозапуск и About со ссылками автора.
- Необязательная проверка GitHub при запуске и раз в час. Новая версия предлагает
  «Обновить / Позже»; кнопка открывает проверенный DMG в браузере. Установка —
  перетаскиванием приложения в «Программы».

В запросы обновлений не входят текст, исключения и идентификаторы устройства.
Пройдены **53 автоматические и 19 изолированных живых проверок**, включая выделение,
обратное преобразование и защищённое поле. После прогона Lado закрыт.

Только Apple Silicon. Подпись ad-hoc, без заверения Apple. Совместимость с прочими
редакторами и браузерами ещё проверяется. Windows и локальная модель — следующие этапы.
