# Lado 0.1.0 — development preview / предварительная сборка

First Python/macOS implementation of Lado. **Editor compatibility validation is
not complete.** This is a development candidate, not a stable release.

Included: pixel logo/icon/banner; native menu-bar UI and settings; offline RU/EN
frequency-based engine; ALL-CAPS protection; explicit word/app exceptions; double
Shift word/selection handling; protected-field gates; About with author links;
bilingual documentation and a phased checklist.

**Privacy:** no typing history, telemetry, model server, account or runtime network
client. Short-lived bounded context in RAM only; preferences and explicit personal
exceptions are intentionally saved. See PRIVACY.md for the exact boundaries.

**Validation:** 36 automated checks pass on macOS. App bundle self-test, ad-hoc
signature and DMG integrity checks pass. Initial idle physical footprint: about
66 MB on the test Mac. Real typing and password-field behavior require completion
of the manual compatibility checks. A Backspace-based replacement failure found
in an initial trial was addressed by replacing that strategy with a bounded,
validated Accessibility operation; successful end-to-end retesting is pending.

macOS arm64 only. Ad-hoc signed, not Apple-notarized. No neural model or Windows
adapter in this candidate. DMG includes an Applications link and installation note.

Первая реализация Lado на Python для macOS. **Проверка совместимости с реальными
редакторами ещё не завершена.** Это сборка для разработки, а не стабильный релиз.

Включены пиксельный фирменный стиль, меню и настройки, локальный алгоритм RU/EN,
защита ЗАГЛАВНЫХ слов, явные исключения, двойной Shift для слова/выделения,
проверки защищённого ввода и About со ссылками автора. README — на двух языках.

Набранный текст не передаётся и не сохраняется в историю; ограниченный контекст
ненадолго остаётся в RAM. Сохраняются только настройки и явные исключения.
Пройдены 36 автоматических проверок, проверены подпись и целостность DMG.
Живое тестирование ещё нужно завершить; подробности в docs/VALIDATION.md.

Только Apple Silicon. Подпись ad-hoc, без заверения Apple. Нейросеть и Windows —
в следующих этапах. Контрольная сумма DMG приложена отдельным файлом.
