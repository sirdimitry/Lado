# Lado 0.1.1-rc.3 — 2026-10-30

Focus and input-safety revision. 132 isolated checks pass. Packaging checks:
strict code signature, bundled-source match, self-test and DMG integrity pass.
Apple Silicon, ad-hoc signed, not notarized. Installed at /Applications/Lado.app.

- Background focus probing with an end-to-end AX deadline and start timestamps.
- Discard in-flight results after focus invalidation; reject stale snapshots.
- Core Foundation field equality; different same-role fields clear context.
- Bounded nested-focus/window search reads metadata, not document text.
- Correct UTF-16 selection slicing after emoji and surrogate-boundary rejection.
- Whole-field reads OFF by default, manual only, capped at 16384 UTF-16 units.
- Automatic correction never reads/replaces the entire field.
- Explicit Restart input; no automatic re-arm after a fault.
- Permission-specific onboarding and user-initiated metadata-only diagnostics.
- Passive observation; no clipboard or synthetic replacement keystrokes.

Optional whole-field edits require a known range and repeated range/value checks.
They may reset formatting and cannot guarantee atomic compare-and-swap against
editor-internal concurrent changes. Keep the option off for strict bounded reads.

The installed final candidate passes 23 isolated native cases, including emoji,
same-role field transitions and continuous typing after layout correction.
A native test exposed an additional first-Shift race after a layout change; it
was fixed, covered by three regression checks and the native suite rerun.
The user reports neither conversion method works in the ChatGPT/Codex field.
This remains unresolved; AppKit results do not certify that editor. Old copies were removed; login remains disabled.
