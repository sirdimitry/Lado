# Lado 0.1.1-rc.7

Fixes WebKit contenteditable replacement: use TextOperationReplacePreserveCase, require the actual replacement response and read the bounded span back. Handles asynchronous selections without treating AX success as proof of editing.

The source patch passed 23/23 live local WKWebView cases, including automatic correction, double Shift, selected paragraphs, emoji and secure-field blocking. See docs/validation/webkit-0.1.1-rc.6-patched-2026-10-31.json.

Codex/ChatGPT and known Chromium browsers are explicitly unsupported. This is NOT a ChatGPT/Codex compatibility fix. Whole-field edits are disabled even with legacy preferences. No synthetic replacement input, clipboard, typing history or telemetry.

Apple Silicon, macOS 13+. Ad-hoc signed; not Apple-notarized. Windows is not built.
