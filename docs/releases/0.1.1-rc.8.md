# Lado 0.1.1-rc.8 — preview

**WebKit and Codex/ChatGPT both verified live in this candidate.**

- WebKit contenteditable: strict `TextOperationReplacePreserveCase`, response validation and bounded read-back. 23/23 live WKWebView cases pass.
- Codex/ChatGPT (Chromium): one bounded, tagged synthetic Backspace + Unicode batch, only after the AX read-back proves the AX setter did not change the text. Maximum 128 characters, no retry, `chromium_synthetic` can disable it. Verification uses `AXStringForRange` for the replaced span only.
- Double Shift fires on the second press (Keyboop-style); any key/mouse between taps cancels it, and synthetic events use flags=0 so the result keeps its case.
- Live Codex check: `ghbdtn ` → `привет `, then double Shift → `ghbdtn `, composer cleared. `last_replacement = range-replaced/synthetic-unicode`.
- 162 isolated tests pass.

Limits: selected text in Chromium is not covered by this fallback; the synthetic check can pause the main run loop for ~0.15–0.2 s; physical input is never suppressed, but a small posting race remains; other Chromium apps are untested. Whole-field edits stay disabled. No clipboard, typing history, network or telemetry.

Packaged as a macOS arm64 DMG; ad-hoc signed, not notarized. macOS 13+. The live reports above concern source runs. Installed-package validation is recorded separately.

The new pre-post gate verifies fresh foreground PID and AX field identity within 150 ms. Synthetic fallback is enabled only for the tested com.openai.codex target; other Chromium apps remain on the AX path. Whole-field writes remain disabled.

Installed-package check: 23/23 local WKWebView cases passed on attempt 3. The first two startup attempts failed before correction; the cause is unresolved and retained in the validation reports. The user confirmed automatic correction and double-Shift reversal in Codex using the installed /Applications/Lado.app after refreshing macOS permission. This is a preview, not a long-session reliability guarantee.

Package checks: 162 isolated tests, strict ad-hoc signature, packaged self-test, installed/built file and symlink equality, DMG integrity, and uploaded/downloaded SHA-256 match all pass.
